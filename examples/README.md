# Choose a task

The same three examples are available in [TypeScript](typescript/) and [Python](python/):

1. [General assistant](typescript/general-assistant/README.md) — find a capability for a task your app did not pre-integrate, then show its connection materials. [Python](python/general-assistant/README.md)
2. [Shopping comparison](typescript/shopping/README.md) — discover relevant product-search capabilities and show how a client could connect. [Python](python/shopping/README.md)
3. [IDE suggestions](typescript/ide/README.md) — suggest a capability from an approved task summary, without background action. [Python](python/ide/README.md)

Start with Search, then read [how to use its results in your own client](../docs/using-search-results.md). The optional [Act preview](../docs/api-and-credentials.md#act-preview) is a separate path with its own user review. See [setup](../docs/getting-started.md) and [verification](../docs/availability-and-verification.md).

The older `agentic-assistant.mjs`, `shopping-concierge.mjs`, and `ide-companion.mjs` commands remain runnable for existing links, but the folders above are the maintained teaching examples.
