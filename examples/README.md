# Choose a task

The same three examples are available in [TypeScript](typescript/) and [Python](python/):

1. [General assistant](typescript/general-assistant/README.md) — find and ask an agent for a task your app did not pre-integrate. [Python](python/general-assistant/README.md)
2. [Shopping comparison](typescript/shopping/README.md) — compare real replies from two product-search agents. [Python](python/shopping/README.md)
3. [IDE suggestions](typescript/ide/README.md) — suggest an agent from an approved task summary, without background action. [Python](python/ide/README.md)

Start with Search. To Communicate, the acting person must approve OAuth and review the exact target and request. Authenticate or Pay only when a real thread returns a structured request and the person separately approves it. See [setup](../docs/getting-started.md) and [verification](../docs/availability-and-verification.md).

The older `agentic-assistant.mjs`, `shopping-concierge.mjs`, and `ide-companion.mjs` commands remain runnable for existing links, but the folders above are the maintained teaching examples.
