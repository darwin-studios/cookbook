# TypeScript examples

- [General assistant](general-assistant/README.md) — find and ask an agent for an unplanned task.
- [Shopping comparison](shopping/README.md) — compare actual responses from independent agents.
- [IDE suggestions](ide/README.md) — suggest an agent from a developer-approved task summary.

Each folder has its own `npm install`, run command, code, and tests. Start with the README for the task you want.
